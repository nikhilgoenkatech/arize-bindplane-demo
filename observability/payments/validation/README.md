Reproduce offline from the repository root:

```bash
python3 -m pip install -r observability/payments/validation/requirements.txt
python3 observability/payments/build.py
python3 observability/payments/validation/validate.py
python3 -m unittest discover -s test/payments -p 'test_dashboard_demo.py'
```

To recapture actual service behavior, install the application's dependencies in the same Python environment, then run:

```bash
python3 observability/payments/validation/capture.py --app-root /path/to/payments-demo
python3 observability/payments/validation/validate.py
```

Recapture replaces the fixture files with a new random run. IDs, amounts, failure attempts and timings will change; update the prose evidence if committing a new capture. Synthetic fixtures are safe demo data, not real customer payments.
